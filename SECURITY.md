# Security Policy

## Supported Versions

We currently support the following versions for security updates:

| Version | Supported          |
| ------- | ------------------ |
| >= 1.0.0| :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Instead, please report them via the **GitHub Private Vulnerability Reporting** feature. 
To do this, go to the [Security tab](https://github.com/dwn10/AntigravityVoiceReader/security/advisories/new) of this repository and click on **Report a vulnerability**. 

This allows you to disclose the vulnerability privately and securely, giving the maintainers time to patch the issue before it becomes public knowledge. 

We will review all submissions and strive to respond within 48 hours.
